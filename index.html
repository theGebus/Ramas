ANTES DE EMPEZAR

Resuelve lo esencial.

¿Dónde escribo estos comandos?

En Git Bash, PowerShell o la terminal de tu editor, con Git instalado. Abre la terminal dentro de la carpeta de tu proyecto.

¿Cuál es la diferencia entre Git y GitHub?

Git registra versiones en tu equipo. GitHub es un servicio para alojar repositorios remotos y colaborar con otras personas.

¿Copiar un comando lo ejecuta?

No. El botón solo copia el ejemplo. Revisa las rutas, nombres de ramas y archivos antes de pegarlo y ejecutarlo en tu terminal.
